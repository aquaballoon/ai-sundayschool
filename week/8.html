  • 수업용 태블릿 하나를 정해 계속 그것으로 출석을 찍으세요.

출석표 만들 때의 지침

출석표에는 아이 정보가 들어갑니다. 두 가지만 지키면 됩니다.

① 실명 대신 가명을 씁니다

프롬프트에 적은 이름은 코드에 그대로 들어갑니다. 누가 누구인지는 교사가 알면 충분합니다.

② 사진은 올리지 않습니다

얼굴은 이름보다 훨씬 강한 정보입니다. 아이 사진은 어떤 경로로도 넣지 않습니다.

가명은 이렇게 정하면 좋습니다
동물 — 다람쥐 · 사슴 · 참새 · 고래 · 나비 · 강아지
성경 인물 — 요셉 · 한나 · 룻 · 사무엘 · 미리암 · 디모데

아이에게 직접 고르게 하면 더 좋습니다. 자기 가명을 좋아하게 되고, 성경 인물로 정하면 그 인물이 누구인지 한 번 더 이야기할 기회가 생깁니다.

이름 앞에 그 가명에 맞는 그림도 붙입니다. 아이들이 글자보다 그림으로 자기 자리를 먼저 찾습니다 — 완성품의 출석 탭에서 확인해 보세요.
기록 자체는 파일로 나가지 않습니다
출석·달란트 기록은 코드가 아니라 그 기기의 저장소에 남습니다. 공개되는 것은 프롬프트에 적어 코드에 박힌 이름뿐입니다.

출석 탭 만들기

  1. 먼저 우리 반 명단을 가명으로 정합니다

    종이에 먼저 적어 보세요. 위 「가명은 이렇게 정하면 좋습니다」의 예시에서 골라도 됩니다.

  2. 출석 화면을 만들어 달라고 합니다

    Claude에 붙여넣기 · 1단계 
    출석 탭을 만들어 줘.

- 우리 반 명단 (이 이름 그대로 써 줘)
  다람쥐 / 사슴 / 참새 / 고래 / 나비
- 날짜는 따지지 말고 온 횟수만 쌓이게 해 줘.
  이름마다 [−] 와 [＋] 버튼. ＋ 를 누르면 1번씩 늘어나고,
  잘못 눌렀으면 − 로 빼게 (지각·결석은 만들지 마)
- 이름 옆에 온 횟수만큼 잎 🌿 이 자라게.
  그 옆에 "5번" 처럼 숫자도 같이. 아이가 자기 잎을 보는 화면이야
- 맨 위에 "우리 반 누적 출석" 합계와 "가장 많이 온 친구"
- 아래에 "오늘 모두 ＋1" 버튼
- 버튼은 손가락으로 누르기 쉽게 크게
- 이름 앞에 그 가명에 맞는 이모지를 붙여 줘.
  다람쥐면 🐿️, 사슴이면 🦌 처럼. 이미지 파일은 쓰지 마.
  목록에 없는 이름에도 그림이 꼭 붙게 하고,
  한 반 안에서 같은 그림이 두 번 나오지 않게 해 줘

  3. 기록이 남게 합니다 — 오늘의 핵심

    Claude에 붙여넣기 · 2단계 
    이제 출석 기록이 남게 해 줘.

- 브라우저를 껐다 켜도, 다음 주에 다시 열어도 남아 있게
- 저장이 안 되는 환경일 수도 있으니, 저장을 시도할 때
  오류가 나면 앱이 멈추지 말고 그냥 넘어가게 해 줘
- 아래에 "출석 처음부터" 버튼도 하나 넣어 줘.
  다만 한 번 누르면 "정말 지울까요?" 로 바뀌고,
  한 번 더 눌러야 실제로 지워지게 해 줘
    출석 탭

    ＋를 누를 때마다 잎이 하나씩 자랍니다. 아이가 자기 줄을 보고 있습니다

  4. 내려받아 올린 뒤 — 반드시 이 시험을 하세요

    Artifact 내려받기 → GitHub → Upload files → Commit changes
    1. 내 주소를 연다
    2. 출석을 두세 명 찍는다
    3. 새로고침한다
    4. 찍은 것이 그대로 있으면 성공
    사라진다면
    Claude 화면에서 열고 있는 것입니다. 주소창을 보세요 — github.io가 있어야 합니다. claude.ai면 사라지는 게 정상입니다.

자주 나오는 문제

새로고침하면 출석이 사라집니다

주소창을 확인하세요. claude.ai에서 열고 있으면 원래 사라집니다. Claude 화면은 저장 공간이 막혀 있습니다.

내아이디.github.io/…에서 열어야 남습니다.

내 태블릿에서는 남는데 다른 기기에서는 안 보입니다

정상입니다. 기록은 서버가 아니라 그 기기 안에 저장됩니다.

그래서 수업용 기기를 하나로 정하는 것이 중요합니다. 여러 기기에서 함께 보려면 서버가 필요한데, 그건 기본 과정의 범위를 넘습니다. 맨 아래 엑스트라(Supabase)에서 해 볼 수 있습니다 — 선택입니다.

휴대폰 시크릿 모드에서 열었더니 안 남습니다

시크릿(비공개) 모드는 창을 닫으면 저장한 것을 지웁니다. 일반 모드로 여세요.

새 파일을 올렸더니 지난 출석이 사라졌습니다

보통은 그렇지 않습니다 — 파일을 바꿔도 저장된 기록은 남습니다.

사라졌다면 Claude가 저장할 때 쓰는 이름표를 바꾼 것입니다. “저장할 때 쓰는 키 이름은 절대 바꾸지 마”라고 말해 두세요.

아이가 스무 명이 넘습니다

명단만 늘리면 됩니다. 지금은 “명단을 20명으로 늘려 줘”라고 하세요. 다음 주(9주)에 만드는 「반 관리」 탭이 생기면, 코드를 고치지 않고 화면에서 이름을 추가·수정·삭제할 수 있습니다.

엑스트라 — 출석을 Supabase에 저장하기

안 해도 됩니다. 수료와 상관없고, 과제 점검에도 들어가지 않습니다. 이번 주 기본 과제를 마치고 여유가 있고 더 해 보고 싶을 때만 해 보세요.
MCP 연결(커넥터)은 무료 Claude도 1개까지 됩니다. 그래서 이 엑스트라는 무료 계정으로도 해 볼 수 있습니다. 다른 커넥터가 이미 연결돼 있다면 무료 계정은 먼저 그것을 제거해야(설정 → 커넥터) Supabase를 연결할 수 있습니다. 둘 이상 계속 연결해 두려면 유료(Pro 이상)가 필요합니다. 무료 계정은 사용량도 빨리 찰 수 있습니다. — 2026년 10월 Anthropic 도움말 기준이며, 바뀔 수 있습니다.

지금 방식의 한계

오늘 만든 출석은 그 기기의 브라우저 안에 저장됩니다. 그래서 세 가지가 아쉽습니다.

  • 찍은 그 기기에서만 보입니다.
  • 브라우저 데이터를 지우면 사라집니다.
  • 다른 선생님이 자기 휴대폰으로 열면 빈 화면입니다.

Supabase는 인터넷에 있는 기록장입니다

지금 출석부는 수업용 태블릿 서랍 속 공책과 같습니다. 그 태블릿을 열어야만 볼 수 있고, 태블릿을 잃어버리면 공책도 함께 사라집니다.

Supabase는 그 공책을 교회 사무실의 공용 장부로 옮기는 일입니다. 장부는 한 권인데, 수업용 태블릿에서도, 다른 선생님 휴대폰에서도, 부장 선생님 컴퓨터에서도 같은 장부를 펼쳐 봅니다. 이런 인터넷 장부를 데이터베이스라고 부릅니다. 작은 반 하나쯤은 무료로 충분합니다.

왜 하나요 — 이럴 때 좋습니다

  • 보조 선생님이 자기 휴대폰으로 출석을 찍고, 담임 선생님이 다른 기기에서 바로 확인할 때
  • 수업용 태블릿이 바뀌거나 고장 나도 기록을 그대로 이어 갈 때
  • 학기 말에 여러 반 기록을 한곳에서 보고 싶을 때

어려운 일은 Claude가 합니다

원래는 장부의 칸(표)을 만들고, 아무나 못 고치게 잠금(보안)을 걸고, 주소와 열쇠(키)를 찾아 페이지에 넣는 일이 꽤 어렵습니다. 그런데 Claude와 Supabase를 MCP로 이으면 그 일을 Claude가 대신 해 줍니다. MCP는 Claude에게 다른 서비스의 문을 열어 주는 연결선입니다. 선생님은 말로 부탁하고, 화면에 뜨는 허락 단추만 누르면 됩니다.

안 하면 어떻게 되나요

아무 문제 없습니다. 수업용 기기 하나로 계속 찍으면 오늘 만든 출석부로 충분합니다. 9주에 백업도 만듭니다. 대신 인터넷 장부에는 지켜야 할 것도 생깁니다 — 아래 「꼭 알아 두세요」를 먼저 읽어 보세요.

주소는 지금 그대로입니다

기록은 Supabase에 저장되고, 페이지는 인터넷만 되면 어디서든 Supabase와 직접 주고받습니다. 그래서 7주에 만든 GitHub Pages 주소(….github.io)에서 그대로 됩니다. 다른 곳에 새로 올릴 필요가 없습니다.

  1. Supabase에 가입합니다

    1. 검색창에 supabase.com을 쳐서 들어갑니다.
    2. 초록색 Start your project를 누릅니다.
    3. Continue with GitHub를 누릅니다. 7주에 만든 GitHub 계정을 그대로 씁니다.
    4. GitHub 화면이 나오면 초록색 Authorize supabase(허락)를 누릅니다.
    5. 조직(Organization) 이름을 물으면 아무 이름이나 적습니다 (예: 우리교회). 요금제(Plan)는 Free(무료)를 고르고 만들기를 누릅니다.

    프로젝트는 직접 만들지 않아도 됩니다. 다음 단계에서 Claude가 만듭니다.

  2. Claude에 Supabase를 연결합니다 (MCP)

    1. claude.ai 왼쪽 아래 내 이름을 누르고 설정을 누릅니다.
    2. 왼쪽 메뉴에서 커넥터를 누릅니다.
    3. 목록에 Supabase가 보이면 그것을 눌러 연결합니다.
    4. 목록에 없으면 커스텀 커넥터 추가를 누르고 이렇게 적습니다.
      이름: Supabase
      주소: https://mcp.supabase.com/mcp
      그리고 추가 → 연결을 누릅니다.
    5. Supabase 화면이 열리면 로그인하고, 조직(1단계에서 만든 이름)을 고른 뒤 Authorize(허락)를 누릅니다.
    6. 대화창으로 돌아와 입력칸 아래 도구 단추(＋ 또는 조절 모양)를 누르고, Supabase가 켜져 있는지 확인합니다.

  3. Claude에게 기록장을 만들어 달라고 합니다

    수업 도구를 만들던 그 대화에 붙여넣으세요. 그래야 4단계에서 Claude가 주소와 키를 이미 알고 있습니다.

    Claude에 붙여넣기 · 엑스트라 1 
    연결된 Supabase 도구를 써서, 우리 반 출석을 저장할 기록장을 네가 직접 만들어 줘.
나는 개발을 모르는 주일학교 교사야. 각 단계를 하기 전에 무엇을 하려는지 쉬운 말로 한두 줄 먼저 설명해 줘.

- 새 프로젝트를 하나 만들어 줘. 이름은 sunday-class, 요금제는 무료(Free),
  지역은 서울과 가까운 곳(Northeast Asia (Seoul))으로
- 만들기 전에 비용이 드는지 확인해서 알려 주고, 0원일 때만 진행해 줘
- 프로젝트가 준비되면 출석 표를 하나 만들어 줘. 칸은 세 개
  · 가명 (글자, 겹치지 않게)
  · 온 횟수 (숫자, 기본값 0)
  · 마지막으로 고친 시각
- 로그인 없이 공개 키로 여는 내 수업 도구 페이지에서
  이 표를 읽고, 새 줄을 넣고, 고칠 수 있게 보안 규칙(RLS)을 켜고 정책을 만들어 줘.
  줄을 지우는 것은 허용하지 마
- 다 되면 프로젝트 주소(Project URL)와 공개 키(publishable 또는 anon key)를 알려 줘
- 비밀 키(service_role 또는 secret key)는 나에게 보여 주지도 말고 어디에도 쓰지 마
    이런 화면이 나와도 놀라지 마세요
    Claude가 Supabase 도구를 쓸 때마다 「허락할까요?」가 뜹니다. 설명을 읽고 허용을 누르세요.
    비용 확인 질문이 나오면 0원(무료)인지 보고 허락합니다. 0원이 아니면 멈추고 Claude에게 물어보세요.
    새 프로젝트가 준비되는 데 1~2분 걸립니다. Claude가 기다렸다가 이어서 합니다.
    확인 한 줄
    Claude가 알려 준 키 이름에 service_role이나 secret이 들어 있으면 그 키는 쓰면 안 됩니다. 페이지에 들어가는 것은 publishable 또는 anon이 붙은 공개 키뿐입니다. 보통은 Claude가 알아서 지키지만, 눈으로 한 번 확인하세요.

  4. 출석 탭이 Supabase를 쓰게 바꿉니다

    3단계와 같은 대화에서 이어서 붙여넣습니다. 다른 대화에서 했다면, 새 대화에 내 최신 index.html을 먼저 첨부하고 Claude가 알려 준 프로젝트 주소와 공개 키도 함께 붙여넣으세요.

    Claude에 붙여넣기 · 엑스트라 2 
    이제 수업 도구의 출석 탭이 방금 만든 Supabase 출석 표를 쓰게 바꿔 줘.

- 외부 라이브러리 없이 파일 하나짜리 HTML 그대로 유지해 줘.
  Supabase와는 브라우저의 fetch로 직접 주고받게
- 프로젝트 주소와 공개 키(publishable 또는 anon key)는 위에서 받은 것을 넣어 줘.
  비밀 키(service_role, secret)는 절대 넣지 마
- 페이지를 열면 Supabase에서 출석을 불러와 보여 줘
- ＋, −, "오늘 모두 ＋1", "출석 처음부터"를 누를 때마다 Supabase에 바로 저장해 줘
- 명단에 있는 가명이 표에 없으면 온 횟수 0으로 새로 넣어 줘
- 지금처럼 기기 안에도 함께 저장해 둬.
  인터넷이 끊기거나 Supabase가 잠들어 있어 저장이 안 되면 앱이 멈추지 말고
  기기에만 저장한 뒤, 출석 탭 위에 작게 "기기에만 저장 중"이라고 보여 줘.
  다시 연결되면 그 표시는 사라지게
- 기기에 저장할 때 쓰는 키 이름은 바꾸지 마
- 출석 탭 말고 다른 탭은 건드리지 마
- 화면 글자는 전부 한국어로

  5. 내려받아 올리고, 두 기기로 시험합니다

    Artifact 내려받기 → GitHub → Upload files → Commit changes

    평소처럼 GitHub에 올리고 1~2분 기다린 뒤 시험하세요.

    1. 내 주소를 태블릿과 휴대폰에서 각각 엽니다.
    2. 태블릿에서 한 아이의 ＋를 누릅니다.
    3. 휴대폰에서 새로고침합니다.
    4. 두 화면의 숫자가 같으면 성공입니다.
    기록장을 눈으로 보고 싶다면
    supabase.com에 들어가 sunday-class 프로젝트를 누르고, 왼쪽 메뉴의 Table Editor를 누르세요. 출석 표에 가명과 온 횟수가 줄줄이 보입니다.

꼭 알아 두세요

① 7일 동안 안 쓰면 잠듭니다
무료 프로젝트는 일주일 동안 아무도 안 쓰면 잠듭니다. 주일에 한 번만 쓰면 딱 경계선입니다. 잠들면 supabase.com에서 그 프로젝트를 열고 Restore를 한 번 누르면 깨어납니다. 잠든 동안에도 출석은 기기에 저장되고 "기기에만 저장 중"이 보입니다. 가능하면 주중에 한 번 내 주소를 열어 두세요.
② 주소를 아는 사람은 기록을 보고 바꿀 수 있습니다
공개 키는 페이지 코드 안에 들어갑니다. 그래서 내 주소를 아는 사람은 마음만 먹으면 기록을 보고 고칠 수 있습니다. 가명만 쓰세요. 실명·사진·연락처는 절대 넣지 않습니다.
③ 먼저 교회와 상의하세요
아이 기록을 인터넷 서버에 두는 일입니다. 시작하기 전에 교회나 부서와 먼저 합의해 주세요.
④ 9주의 백업은 그대로 만듭니다
Supabase가 있어도 다음 주에 만드는 백업 텍스트는 꼭 만들어 두세요. 기록장이 잠들거나 문제가 생겨도 되살릴 수 있습니다.

엑스트라에서 자주 막히는 곳

「커스텀 커넥터 추가」가 안 보이거나 눌리지 않습니다

설정 → 커넥터(Connectors) 화면 아래쪽에 「커스텀 커넥터 추가」가 있습니다. 화면 모양은 가끔 바뀌니 「커넥터」라는 글자를 찾아보세요. 단추가 눌리지 않거나 「더 추가할 수 없다」고 나오면, 무료 계정에 이미 커넥터가 하나 연결돼 있는 것입니다. 쓰지 않는 커넥터를 제거하거나, 둘 이상 쓰려면 유료(Pro 이상)가 필요합니다.

두 기기의 숫자가 다릅니다

한쪽이 아직 옛 파일을 보고 있을 수 있습니다. 강력 새로고침을 해 보세요 — 컴퓨터는 Ctrl+Shift+R (맥은 Cmd+Shift+R), 휴대폰은 브라우저를 완전히 닫았다가 다시 엽니다.

출석 탭 위에 "기기에만 저장 중"이 보이면 그 기기는 Supabase에 닿지 못한 것입니다. 인터넷 연결과, 아래의 「잠들었어요」를 확인하세요.

Supabase가 잠들었다고 나옵니다

supabase.com에 들어가 sunday-class를 누르고 Restore를 누르세요. 몇 분 뒤 깨어납니다. 그동안 찍은 출석은 기기에 남아 있습니다.

키가 뭔지, 어디 있는지 모르겠습니다

몰라도 됩니다. 4단계에서 Claude가 알아서 넣어 줍니다.

직접 보고 싶다면 Supabase에서 프로젝트를 열고 Project Settings → API를 누르세요. publishable이나 anon이 붙은 것이 공개 키입니다. service_role / secret은 절대 페이지에 넣지 않습니다.
