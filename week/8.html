다만 「내 기기 안에」 남습니다

기록은 그 기기의 브라우저 안에 저장됩니다. 서버로 가지 않습니다. 그래서 이런 성질이 있습니다.

  • 수업용 태블릿 하나를 정해 계속 그것으로 출석을 찍으세요.
  • 다른 기기에서 같은 주소를 열면 그 기기의 기록이 보입니다 — 빈 화면입니다.
  • 브라우저 기록·데이터를 지우면 출석도 지워집니다.

출석 탭 만들기

  1. 먼저 우리 반 명단을 별명으로 정합니다

    종이에 먼저 적어 보세요. 아이가 좋아할 별명이면 더 좋습니다.

    예시
    1번 민들레 · 2번 해바라기 · 3번 도토리 · 4번 초록이 · 5번 파랑새

  2. 출석 화면을 만들어 달라고 합니다

    Claude에 붙여넣기 · 1단계 
    출석 탭을 만들어 줘.

- 우리 반 명단 (이 이름 그대로 써 줘)
  1번 민들레 / 2번 해바라기 / 3번 도토리 / 4번 초록이 / 5번 파랑새
- 이름마다 오른쪽에 버튼 3개: 출석 / 지각 / 결석
  누르면 색이 칠해지고, 같은 걸 다시 누르면 취소되게
  (출석은 초록, 지각은 주황, 결석은 빨강)
- 맨 위에 오늘 집계: 출석 몇 명, 지각 몇 명, 결석 몇 명
- 아래에 "모두 출석" 버튼과 "오늘 지우기" 버튼
- 버튼은 손가락으로 누르기 쉽게 크게

  3. 기록이 남게 합니다 — 오늘의 핵심

    Claude에 붙여넣기 · 2단계 
    이제 출석 기록이 남게 해 줘.

- 브라우저를 껐다 켜도, 다음 주에 다시 열어도 남아 있게
- 날짜별로 쌓이게 (오늘 것을 찍으면 지난주 것은 그대로)
- 아래에 "누적 출석" 칸을 만들어
  이름마다 "3 / 4주"처럼 몇 주 중 몇 번 나왔는지 보여 줘
  (지각도 나온 것으로 세 줘)
- 저장이 안 되는 환경일 수도 있으니, 저장을 시도할 때
  오류가 나면 앱이 멈추지 말고 그냥 넘어가게 해 줘
    출석 탭

    누르면 도장 찍히듯 색이 칠해지고, 아래에 누적이 쌓입니다

  4. 내려받아 올린 뒤 — 반드시 이 시험을 하세요

    Artifact 내려받기 → GitHub → Upload files → Commit changes
    1. 내 주소를 연다
    2. 출석을 두세 명 찍는다
    3. 새로고침한다
    4. 찍은 것이 그대로 있으면 성공

새로고침하면 출석이 사라집니다

주소창을 확인하세요. claude.ai에서 열고 있으면 원래 사라집니다. Claude 화면은 저장 공간이 막혀 있습니다.

내아이디.github.io/…에서 열어야 남습니다.

내 태블릿에서는 남는데 다른 기기에서는 안 보입니다

정상입니다. 기록은 서버가 아니라 그 기기 안에 저장됩니다.

그래서 수업용 기기를 하나로 정하는 것이 중요합니다. 여러 기기에서 함께 보려면 서버가 필요한데, 그건 이 과정의 범위를 넘습니다.

휴대폰 시크릿 모드에서 열었더니 안 남습니다

시크릿(비공개) 모드는 창을 닫으면 저장한 것을 지웁니다. 일반 모드로 여세요.

새 파일을 올렸더니 지난 출석이 사라졌습니다

보통은 그렇지 않습니다 — 파일을 바꿔도 저장된 기록은 남습니다.

사라졌다면 Claude가 저장할 때 쓰는 이름표를 바꾼 것입니다. “저장할 때 쓰는 키 이름은 절대 바꾸지 마”라고 말해 두세요.

아이가 스무 명이 넘습니다

명단만 늘리면 됩니다. “명단을 20명으로 늘리고, 화면에서 이름을 추가·수정·삭제할 수 있게 해 줘”라고 하세요. 코드를 고치지 않고 화면에서 관리할 수 있게 됩니다.
