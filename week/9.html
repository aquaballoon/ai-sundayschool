달란트 블록 — 달란트 통장과 학기 마무리

마지막 서랍을 채웁니다. 그리고 이 도구를 다음 단원에도 계속 쓸 수 있게 정리합니다.

소요 50~70분 지난주 필요 출석까지 된 파일 채우는 탭 달란트 · 마무리

강의안

달란트는 상이 아니라 기록입니다

달란트를 「잘한 아이에게 주는 상」으로만 쓰면, 늘 같은 아이가 받습니다. 조금만 바꾸면 달라집니다.

이렇게 쓰면 정답을 맞힌 아이에게 준다
→ 아는 아이만 계속 쌓입니다.
이렇게 쓰면 용기 내어 말한 아이, 친구를 도운 아이, 처음 손든 아이에게 준다
→ 모든 아이에게 받을 길이 열립니다.
＋5 버튼을 만드는 이유
특별한 순간을 표시하기 위해서입니다. 한 개는 흔한 일, 다섯 개는 오래 기억할 일 — 아이도 그 차이를 압니다.

그리고 오늘, 백업을 배웁니다

기록은 그 기기 안에만 있습니다. 태블릿을 잃어버리거나 브라우저 데이터를 지우면 사라집니다.

그래서 학기 말에 기록을 글로 뽑아 두는 기능을 함께 만듭니다. 카톡 「나에게 보내기」에 붙여 두면 그것이 백업입니다.

따라하기

달란트 탭 만들고 마무리하기

  1. 달란트 통장을 만듭니다

    Claude에 붙여넣기 · 1단계 
    달란트 탭을 만들어 줘.

- 출석 탭과 같은 명단을 쓰게 (따로 만들지 말고 같이 쓰게)
- 아이들이 보는 화면이니 받은 달란트를 금메달 그림으로 쌓아 보여 줘.
  10개가 모이면 큰 메달 하나로 묶고, 너무 많으면 "+12" 처럼 줄여 줘
- 이름마다 오른쪽에 버튼: [−] [＋] [＋5]
  · ＋는 1개, ＋5는 5개 주기
  · −는 1개 빼기, 0 아래로는 안 내려가게
- 맨 위에 "반 전체 합계"와 "최다 받은 아이"
- 달란트를 줄 때 화면 아래에 "다람쥐 +5 달란트" 같은 알림이 잠깐 뜨게
- 출석과 똑같이 기록이 남게 (껐다 켜도 유지)
- 맨 아래에 "달란트 처음부터" 버튼.
  한 번 누르면 "정말 지울까요?"로 바뀌고 한 번 더 눌러야 지워지게
- 버튼은 손가락으로 누르기 쉽게 크게
    달란트 탭

    ＋를 누르면 숫자가 올라가고 아래에 알림이 잠깐 뜹니다

  2. 「반 관리」 탭을 채웁니다

    새 학기에 아이가 바뀌어도 코드를 안 고치게 하기 위해서입니다.

    Claude에 붙여넣기 · 2단계 
    "반 관리" 탭 안을 채워 줘.

- 이름을 눌러 바로 고칠 수 있게
- 새 아이를 추가하는 칸과 "추가" 버튼
- 아이마다 "빼기" 버튼으로 명단에서 삭제
- 그 아래에 반 이름을 바꾸는 칸
- 명단은 출석·달란트 탭과 같은 것을 쓰게 (여기서 고치면 양쪽에 반영되게)
- 안내 문구: "아이 실명 대신 가명을 쓰세요. 사진은 올리지 마세요.
  주소를 아는 사람은 누구나 볼 수 있습니다."

  3. 백업 기능을 넣습니다

    Claude에 붙여넣기 · 3단계 
    학기 기록을 백업할 수 있게 해 줘.

- 달란트 탭 맨 아래에 "학기 기록 꺼내기" 버튼
- 누르면 화면 안에 텍스트 상자가 열리고 이런 내용이 들어가게

  [우리 반 기록] 초등 3부 햇살반
  · 다람쥐 — 출석 8번, 달란트 24개
  · 사슴 — 출석 9번, 달란트 18개
  ...

- 사람이 읽는 줄 아래에, 되살릴 때 쓸 수 있게
  기계가 읽는 한 줄(JSON)도 같이 넣어 줘
- 그 아래에 "이 기록 다시 불러오기" 버튼과 붙여넣는 칸도 만들어 줘.
  붙여넣은 것에서 그 한 줄을 찾아 기록을 되살리게
- 클립보드 복사는 안 될 수도 있으니, 텍스트 상자에 그대로 보여 주고
  교사가 직접 복사할 수 있게 해 줘
    이게 왜 중요한가
    태블릿이 바뀌거나 브라우저를 정리해도, 이 텍스트만 있으면 되살릴 수 있습니다. 학기 말에 한 번은 꼭 꺼내 두세요.

  4. 마지막으로 올리고, 여덟 탭을 모두 확인합니다

    Artifact 내려받기 → GitHub → Upload files → Commit changes

    내 주소를 열고 공과 · 성경 이야기 · 퀴즈 · 짝 맞추기 · 찬양 · 출석 · 달란트 · 반 관리를 차례로 눌러 봅니다. 여덟 개가 다 돌면 완성입니다.

    다음 단원에 다시 쓰려면
    Claude에 이렇게 부탁하세요 — “공과 내용과 퀴즈 문제만 「모세와 홍해」로 바꿔 줘. 출석·달란트 기록은 그대로 둬.”
    성경 이야기 그림도 “바다와 모세로 바꿔 줘”라고 하면 됩니다. 찬양 두 곡도 새 단원에 맞는 곡으로 바꿔 달라고 하세요. 뼈대는 계속 씁니다.

내년에도 쓸 수 있나요

쓸 수 있습니다. GitHub Pages는 무료이고 기한이 없습니다.

새 학기에는 「반 관리」 탭에서 아이들을 바꾸고, 공과·퀴즈 내용만 새 단원으로 바꾸면 됩니다. 지난 학기 기록은 백업으로 꺼내 두고 새로 시작하는 것을 권합니다.

부모님도 볼 수 있게 하고 싶습니다

대신 백업 텍스트를 카톡으로 보내는 것이 가장 간단합니다 — “다람쥐 출석 8번, 달란트 24개”처럼 그 아이 줄만 잘라 보내세요. 반 전체 기록이나 뒤쪽의 긴 글자는 보내지 않습니다.

부모가 직접 들어와 보는 화면은 서버가 필요해서 이 과정의 범위를 넘습니다. 아이 정보를 인터넷에 올리는 일이라 신중해야 할 부분이기도 합니다.

엑스트라 1 — 달란트와 반 명단도 Supabase로

안 해도 됩니다. 수료와 상관없고, 과제 점검에도 들어가지 않습니다. 이번 주 기본 과제를 마치고 여유가 있고 더 해 보고 싶을 때만 해 보세요.
MCP 연결(커넥터)은 무료 Claude도 1개까지 됩니다. 8주에 연결한 Supabase를 그대로 쓰므로 무료 계정으로도 됩니다. — 2026년 10월 Anthropic 도움말 기준이며, 바뀔 수 있습니다.

8주 엑스트라에서 출석을 Supabase에 옮겼다면, 오늘은 달란트와 반 명단도 옮깁니다. 그러면 반 관리에서 이름을 바꿨을 때 모든 기기에 똑같이 반영됩니다. 다른 선생님 휴대폰에서도, 수업용 태블릿에서도 같은 명단과 같은 달란트가 보입니다.

주소도 그대로입니다. 7주에 만든 GitHub Pages 주소에서 Supabase와 연동됩니다.

8주 엑스트라를 아직 안 하셨다면
Supabase 가입과 Claude 연결은 그쪽에 있습니다. 8주 엑스트라를 먼저 하고 돌아오세요.

  1. 같은 기록장에 표 두 개를 더 만듭니다

    수업 도구를 만들던 대화에서, 입력칸 아래 도구 단추를 눌러 Supabase가 켜져 있는지 먼저 확인하세요.

    Claude에 붙여넣기 · 엑스트라 1 
    연결된 Supabase 도구를 써서, 8주에 만든 sunday-class 프로젝트에 표를 더 만들어 줘.
새 프로젝트는 만들지 마. 나는 개발을 모르는 교사라서, 각 단계 전에 무엇을 하는지 쉬운 말로 한두 줄 설명해 줘.

- 달란트 표: 가명(글자, 겹치지 않게), 달란트 수(숫자, 기본값 0, 0보다 작아지지 않게), 마지막으로 고친 시각
- 반 명단 표: 가명(글자, 겹치지 않게), 보여 줄 순서(숫자)
- 반 이름을 담을 작은 표: 반 이름(글자) 한 줄
- 지금 출석 표에 있는 가명들을 반 명단 표에 순서대로 넣어 줘
- 로그인 없이 공개 키로 여는 내 수업 도구 페이지에서
  세 표를 읽고, 새 줄을 넣고, 고칠 수 있게 보안 규칙(RLS)을 켜고 정책을 만들어 줘.
  반 명단 표만 줄을 지울 수 있게 하고, 다른 표는 지우기를 허용하지 마
- 비밀 키(service_role 또는 secret key)는 보여 주지도 말고 어디에도 쓰지 마
- 다 되면 무엇을 만들었는지 짧게 정리해 줘

    도구를 쓸 때마다 뜨는 「허락할까요?」는 설명을 읽고 허용을 누르면 됩니다.

  2. 달란트 탭과 반 관리 탭이 Supabase를 쓰게 바꿉니다

    같은 대화에서 이어서 붙여넣습니다. 다른 대화라면 내 최신 index.html을 먼저 첨부하세요.

    Claude에 붙여넣기 · 엑스트라 2 
    이제 달란트 탭과 반 관리 탭도 Supabase를 쓰게 바꿔 줘. 출석 탭에서 한 방식 그대로.

- 외부 라이브러리 없이 파일 하나짜리 HTML 그대로. Supabase와는 fetch로 직접 주고받게
- 출석 탭에 넣은 프로젝트 주소와 공개 키를 그대로 써 줘. 비밀 키는 절대 넣지 마
- 달란트: 페이지를 열면 Supabase에서 불러오고, ＋, ＋5, −, "달란트 처음부터"를 누를 때마다 바로 저장
- 반 명단과 반 이름: Supabase의 반 명단 표와 반 이름 표에서 불러오고,
  반 관리 탭에서 추가·고치기·빼기를 하면 바로 저장
- 반 관리에서 이름을 바꾸면 출석 표와 달란트 표의 같은 가명도 함께 바뀌게
- 출석·달란트 탭은 이 반 명단 하나를 같이 쓰게
- 지금처럼 기기 안에도 함께 저장해 둬. 인터넷이 끊기거나 Supabase가 잠들어 있으면
  앱이 멈추지 말고 기기에만 저장한 뒤, 그 탭 위에 작게 "기기에만 저장 중"이라고 보여 줘
- 기기에 저장할 때 쓰는 키 이름은 바꾸지 마
- "학기 기록 꺼내기"와 "이 기록 다시 불러오기"는 그대로 두고, 되살릴 때 Supabase에도 저장되게
- 달란트·반 관리 탭 말고 다른 탭은 건드리지 마
- 화면 글자는 전부 한국어로

  3. 내려받아 올리고, 두 기기로 시험합니다

    Artifact 내려받기 → GitHub → Upload files → Commit changes
    1. 1~2분 기다린 뒤, 내 주소를 태블릿과 휴대폰에서 엽니다.
    2. 태블릿에서 한 아이에게 ＋5를 누릅니다.
    3. 태블릿의 반 관리 탭에서 한 아이의 가명을 바꿉니다 (예: 참새 → 제비).
    4. 휴대폰에서 새로고침합니다. 달란트 숫자와 바뀐 이름이 똑같으면 성공입니다.
    백업은 여전히 쓸모 있습니다
    「학기 기록 꺼내기」는 계속 쓰세요. Supabase가 잠들었을 때, 그리고 새 학기를 처음부터 시작할 때 지난 기록을 남겨 두는 가장 쉬운 방법입니다.
다시 한 번 — 두 가지

엑스트라 2 — 생일을 넣고, 홈에서 축하하기

안 해도 됩니다. 수료와 상관없고, 과제 점검에도 들어가지 않습니다. 이번 주 기본 과제를 마치고 여유가 있고 더 해 보고 싶을 때만 해 보세요. MCP도 Supabase도 필요 없습니다 — 무료 계정으로 됩니다.

반 관리에 생일 칸을 더합니다. 그러면 생일인 친구가 있는 주일에 화면 맨 위에 「오늘의 친구 — 생일 축하해요!」가 크게 나옵니다. 아이 이름을 한 번 더 불러 줄 기회입니다.

주일학교는 일주일에 한 번 모이니, 오늘이 생일인 친구뿐 아니라 이번 주(주일~토요일)에 생일인 친구도 함께 보여 줍니다. 10주에 커리큘럼 홈을 만들면 이 축하 인사는 홈 맨 위에 나옵니다.

완성품 예시를 열면 홈 맨 위에서 볼 수 있습니다 — 예시로 첫 친구의 생일을 오늘로 넣어 두었습니다.

생일도 아이 정보입니다 — 두 가지만 지키세요
① 월·일만 넣습니다. 태어난 해는 넣지 않습니다.
② 생일은 프롬프트에 적지 말고, 다 만든 뒤 반 관리 화면에서 고릅니다. 프롬프트에 적은 것은 코드에 그대로 들어가 주소를 아는 누구나 볼 수 있지만, 화면에서 고른 것은 그 기기(또는 Supabase)에만 저장됩니다.

  1. 반 관리에 생일 칸을 더합니다

    Claude에 붙여넣기 · 1단계 
    "반 관리" 탭의 명단에 생일 칸을 더해 줘.
- 이름 옆에 생일을 고르는 칸: "월"과 "일" 두 개 (태어난 해는 받지 마)
- 손가락으로 고르기 쉽게 크게
- 고르면 바로 저장되게. 출석·달란트 기록처럼 껐다 켜도 남게
- 저장할 때 쓰는 키 이름과 지금 있는 기록은 절대 바꾸지 마
- 다른 탭은 건드리지 마

  2. 생일인 친구가 맨 위에 나오게 합니다

    Claude에 붙여넣기 · 2단계 
    생일 축하 칸을 만들어 줘.
- 화면 맨 위(탭 위)에 크게. 커리큘럼 홈이 있으면 홈 맨 위에
- 오늘이 생일인 친구가 있으면:
  🎂 그림, "오늘의 친구", 가명과 그 친구 그림,
  "다람쥐, 생일 축하해요!" 처럼 큰 글씨,
  그 아래 "하나님이 다람쥐를 이 세상에 보내 주셔서 정말 기뻐요.
  우리 모두 축하해 줘요!" 같은 따뜻한 한 줄
  (이름 뒤의 을/를은 받침에 맞게)
- "함께 축하하기" 단추를 누르면 색종이 축하 효과
- 이번 주(주일~토요일)에 생일인 친구는 아래에 작게
  "이번 주 생일 · 사슴 (10월 21일)" 처럼
- 생일인 친구가 없으면 이 칸은 아예 보이지 않게
- 따뜻한 살구색·분홍색 바탕, 화면 글자는 전부 한국어로

  3. 오늘 날짜로 시험해 봅니다

    내려받아 GitHub에 올린 뒤(7주와 같습니다), 반 관리에서 한 친구의 생일을 오늘 날짜로 골라 보세요. 맨 위에 축하 인사가 나오면 성공입니다. 확인했으면 진짜 생일로 다시 바꿔 둡니다.

  4. Supabase 엑스트라를 했다면 — 생일도 함께 옮깁니다

    위 엑스트라 1을 마쳤다면, 같은 대화에서 이렇게 부탁하면 모든 기기에서 같은 생일이 보입니다. 하지 않았다면 이 단계는 건너뛰세요.

    Claude에 붙여넣기 · 선택 
    Supabase의 반 명단 표에 생일 칸을 하나 더해 줘 (월-일만, 예: 10-18).
반 관리에서 고른 생일이 Supabase에 저장되고, 다른 기기에서도 보이게 해 줘.
Supabase가 안 될 때는 지금처럼 기기에 저장하고, 다른 탭은 건드리지 마.
무엇을 바꾸는지 먼저 쉬운 말로 설명하고 허락을 받아 줘.
수업에서 이렇게 써 보세요
예배를 마치고 분반공부를 시작할 때 홈을 열어 두면, 생일인 친구가 있는 주일에는 저절로 축하 인사가 뜹니다. 「함께 축하하기」를 누르고 반 전체가 생일 축하 노래를 불러 주세요. 그 친구를 위해 한 문장 기도해 주면 더 좋습니다.
