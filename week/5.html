그림 성경 이야기 — 끌어 옮기는 융판

화면 위 인물을 손가락으로 옮기며 이야기를 들려줍니다. 종이 융판이 하던 일을 태블릿이 합니다.

소요 50~70분 지난주 필요 공과가 채워진 Artifact 채우는 탭 그림 성경 이야기
  • 이번 주에 할 수 있게 되는 것
  • 배경과 인물을 그림으로 만든다 (그림 실력 필요 없음)
  • 손가락으로 끌어 옮기는 화면을 만든다
  • 아이가 직접 만져 보게 하는 수업 방법을 안다

완성품의 그림 성경 이야기 탭에서 다윗을 끌어 보세요. 오늘 이 화면까지 갑니다.

강의안

그림은 AI가 그립니다. 다만 방식이 중요합니다

인물 그림을 만드는 방법은 두 가지입니다. 둘째를 씁니다.

그림 파일로 만들기 AI 그림 생성기로 png를 만들어 붙입니다.
→ 파일이 여러 개가 되고, 화질이 깨지고, 올리기도 번거롭습니다.
코드로 그리기 (SVG) Claude가 도형으로 그림을 그려 파일 안에 넣습니다.
→ 파일은 계속 하나. 아무리 확대해도 안 깨집니다. 색도 말로 바꿉니다.
그래서 프롬프트에 이 한 줄을 꼭 넣습니다
“그림은 SVG 도형으로 코드 안에 직접 그려 줘. 이미지 파일은 쓰지 마.”

이 화면을 아이에게 넘기세요

교사가 옮기며 설명하는 것도 좋지만, 더 좋은 것은 아이가 직접 옮기게 하는 것입니다.

“누가 다윗을 골리앗 앞으로 데려다 줄래요?” — 한 아이가 나와서 손가락으로 옮깁니다. 그 순간 이야기는 그 아이의 것이 됩니다.

따라하기

「그림 성경 이야기」 탭 만들기

  1. 배경과 인물을 만들어 달라고 합니다

    Claude에 붙여넣기 · 1단계 
    「그림 성경 이야기」 탭을 만들어 줘.

- 배경: 엘라 골짜기. 위는 하늘, 가운데 언덕, 아래 풀밭
- 인물과 사물: 다윗(작은 소년), 골리앗(다윗보다 훨씬 큰 거인),
  양, 물맷돌, 나무, 장막
- 골리앗은 다윗보다 확실히 크게 그려 줘. 크기 차이가 이 이야기의 핵심이야
- 그림은 전부 SVG 도형으로 코드 안에 직접 그려 줘.
  이미지 파일이나 인터넷 주소는 쓰지 마
- 아이들이 보는 것이니 따뜻하고 부드러운 색으로
    얼굴은 단순하게
    사람 얼굴을 자세히 그리라고 하면 어색해집니다. “얼굴은 단순하게, 표정은 넣지 마”라고 하면 오히려 보기 좋습니다.

  2. 손가락으로 끌 수 있게 합니다

    Claude에 붙여넣기 · 2단계 
    이제 인물과 사물을 손가락으로 끌어 옮길 수 있게 해 줘.

- 태블릿 터치와 마우스 둘 다 되게 (포인터 이벤트로)
- 끌고 있는 것이 다른 것 위로 올라오게
- 화면 밖으로는 나가지 않게
- 배경(하늘, 언덕, 풀밭)은 고정 — 인물만 움직이게
- 아래에 "처음으로" 버튼을 넣어 원래 자리로 되돌릴 수 있게
    「그림 성경 이야기」 탭

    작은 다윗을 큰 골리앗 앞으로 — 크기 차이가 그대로 메시지가 됩니다

  3. 태블릿에서 직접 만져 봅니다

    마우스로는 잘 되는데 손가락으로는 안 되는 경우가 있습니다. 반드시 실제 태블릿에서 확인하세요.

    손가락으로 끌면 화면이 같이 스크롤되면
    이렇게 말하세요 — “융판 위에서는 손가락으로 끌 때 화면이 스크롤되지 않게 해 줘 (touch-action: none)”

  4. 링크로 남기고 파일도 보관합니다

    Artifact 칸 위쪽의 공유(Share)로 링크를 만들어 과제로 냅니다. 그리고 내려받기로 index.html을 내 컴퓨터에도 저장하세요 — 7주에 이 파일을 씁니다.

    Artifact → 공유(Share) → 링크 복사  ·  Artifact → 내려받기 → index.html 보관

    만든 링크를 태블릿에서 열어 손가락으로 직접 끌어 보세요.

자주 나오는 문제

그림이 이상하게 나옵니다

한 번에 완벽하게 나오지 않습니다. 하나씩 짚어 말하면 됩니다 — “골리앗을 1.5배 크게”, “다윗 옷을 파란색으로”, “나무를 오른쪽으로 옮겨”.

사람보다 도형에 가깝게 부탁하면 훨씬 안정적입니다.

마우스로는 되는데 태블릿에서는 안 끌립니다

터치 처리가 빠진 것입니다. “마우스와 터치 둘 다 되도록 포인터 이벤트로 다시 만들어 줘”라고 하세요.

인물이 화면 밖으로 나가 사라집니다

“인물이 화면 밖으로 나가지 않도록 가장자리에서 멈추게 해 줘”라고 하면 됩니다. 급하면 「처음으로」를 눌러 되돌리세요.

수업 중에 아이가 다 흐트러뜨렸습니다

그게 좋은 수업입니다. 「처음으로」를 누르면 3초 만에 정리됩니다.

참고로 융판 배치는 저장되지 않습니다. 매 시간 새로 꾸미는 것이 정상입니다 — 출석·달란트와 달리 남길 이유가 없는 정보이기 때문입니다.
