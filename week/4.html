첫 페이지 만들고 인터넷에 올리기

오늘 우리 반 수업 도구의 뼈대를 만들고, 진짜 인터넷 주소를 받습니다. 이 주소는 학기 내내 그대로 씁니다.

소요 60~80분 준비물 노트북 또는 데스크톱 계정 Claude(무료) · GitHub(무료)
  • 이번 주에 할 수 있게 되는 것
  • Claude에게 부탁해 파일 하나짜리 웹페이지를 만든다
  • 그 파일을 GitHub Pages에 올려 인터넷 주소를 받는다
  • 고친 파일을 다시 올려 화면을 바꾼다

강의안

왜 두 곳을 쓰나요?

Claude는 만드는 곳이고, GitHub Pages는 쓰는 곳입니다. 역할이 다릅니다.

　ClaudeGitHub Pages
하는 일코드를 만들고 고친다만든 것을 주소로 열어 준다
출석 기록이 남나요남지 않는다남는다
주소대화마다 달라진다학기 내내 고정
비용무료무료
여기가 핵심입니다
Claude 화면 안에서는 출석·달란트가 새로고침하면 사라집니다. 브라우저 저장소가 막혀 있기 때문입니다. GitHub Pages에 올리면 그 제약이 사라져 기록이 남습니다. 그래서 8주까지 미루지 않고 오늘 배포부터 배웁니다.

오늘 만들 것

제목과 날짜, 그리고 탭 다섯 개. 탭 안은 아직 비어 있습니다. 다음 주부터 하나씩 채웁니다.

따라하기 ①

Claude로 뼈대 만들기

  1. Claude를 열고 새 대화를 시작합니다

    claude.ai에 가입하고 로그인합니다. 무료 계정이면 충분합니다.

    이 대화창을 학기 내내 씁니다
    오늘 만든 대화에 계속 이어서 부탁하면, 지난주에 만든 것 위에 쌓입니다. 대화 제목을 「우리 반 수업 도구」로 바꿔 두고 즐겨찾기 해 두세요.

  2. 아래 내용을 그대로 붙여넣습니다

    반 이름만 우리 반으로 바꾸세요.

    Claude에 붙여넣기 
    주일학교 교사가 태블릿으로 쓸 수업 도구 웹페이지를 만들어 줘.

- 외부 라이브러리 없이 파일 하나짜리 HTML로 만들어 줘
- 맨 위에 반 이름 "초등 3부 햇살반"과 오늘 날짜를 보여 줘
- 그 아래 탭 6개: 공과 / 융판 / 퀴즈 / 출석 / 달란트 / 반 관리
- 지금은 각 탭 안에 "다음 주에 만듭니다"라고만 보여 줘
- 손가락으로 누르는 것이라 버튼은 크게 (최소 44px)
- 배경은 따뜻한 아이보리 #F9F9F6, 글자는 진한 남색 #2C3E50
- 화면 글자는 전부 한국어로
    Claude
    주일학교 수업 도구를 만들어 줘…
    만들었습니다. 오른쪽에서 확인하세요.
    미리보기Artifact

    오른쪽 Artifact 칸에 화면이 바로 뜹니다

  3. 화면을 보고 마음에 안 들면 말로 고칩니다

    코드를 건드릴 필요가 없습니다. 그냥 대화창에 이어서 쓰면 됩니다.

    고칠 때 쓰는 말 (예시) 
    탭 글씨가 작아. 더 크게 해 줘.
반 이름 밑에 오늘 날짜를 요일까지 보여 줘.
공과 탭이 처음에 열려 있게 해 줘.
따라하기 ②

인터넷에 올리기

처음 한 번만 어렵습니다. 다음 주부터는 STEP 9만 반복하면 됩니다.

  1. 코드를 파일로 내려받습니다

    Artifact 칸 오른쪽 위 메뉴에서 내려받기를 누릅니다.

    내려받기 버튼이 안 보이면
    Claude에게 이렇게 부탁하세요 — “전체 코드를 하나로 보여 줘”. 그 코드를 전부 복사해서 메모장에 붙여넣고, 저장할 때 파일 이름을 index.html로, 파일 형식을 모든 파일로 바꿔 저장하면 똑같습니다.
    파일 이름은 반드시 index.html
    다른 이름이면 주소로 열리지 않습니다. 이것 하나만 지키면 됩니다.

  2. GitHub에 가입합니다

    github.com/signup — 이메일과 비밀번호, 사용자 이름만 정하면 됩니다. 무료입니다.

    사용자 이름이 곧 주소가 됩니다
    hansem으로 정하면 주소가 hansem.github.io/…가 됩니다. 영문 소문자로 짧게 정하세요. 나중에 바꾸기 번거롭습니다.

  3. 저장소(Repository)를 하나 만듭니다

    오른쪽 위 ＋ → New repository

    GitHub · New repository

    이름은 영문 소문자로, 공개 범위는 Public

    Public을 꼭 고르세요
    무료 계정은 공개 저장소에서만 페이지가 열립니다. Private으로 만들면 주소가 작동하지 않습니다.

    공개라는 말은 주소를 아는 사람은 누구나 볼 수 있다는 뜻입니다. 그래서 이 과정에서는 아이 실명과 사진을 넣지 않습니다. 동물이나 성경 인물 가명을 씁니다.

  4. 파일을 올립니다

    저장소 화면에서 Add file → Upload files → 아까 받은 index.html을 끌어다 놓습니다.

    Upload files

    끌어다 놓고 아래 Commit changes 누르면 끝

  5. 페이지 기능을 켭니다 — 이건 처음 한 번만

    저장소 위쪽 Settings → 왼쪽 목록에서 Pages

    Settings · Pages

    Source는 Deploy from a branch, 브랜치는 main + / (root)

  6. 1~2분 기다렸다가 주소를 엽니다

    같은 Pages 화면 위쪽에 주소가 나타납니다. 이런 모양입니다.

    내 페이지 주소
    https://내아이디.github.io/sunday-class/
    이 주소를 즐겨찾기에 넣으세요
    학기 내내 이 주소 하나만 씁니다. 태블릿 홈 화면에 추가해 두면 앱처럼 열립니다.
    바로 안 열려도 정상입니다
    첫 배포는 1~2분 걸립니다. 404가 뜨면 조금 기다렸다 새로고침하세요.

  7. 고친 뒤 다시 올리기 — 다음 주부터 매주 이것만

    Claude에서 고친다 → 내려받는다 → 같은 저장소에 같은 이름으로 다시 올린다. 덮어써집니다.

    1. Add file → Upload files
    2. 새 index.html을 끌어다 놓는다
    3. Commit changes
    4. 1분 뒤 내 주소를 새로고침
    바뀐 게 안 보이면
    브라우저가 옛 화면을 기억하고 있는 것입니다. 강력 새로고침을 하세요 — 윈도우는 Ctrl+Shift+R, 맥은 ⌘+Shift+R.

자주 나오는 문제

주소를 열었는데 404가 뜹니다

세 가지 중 하나입니다.

① 아직 배포 중입니다. 1~2분 기다렸다 새로고침하세요.
② 파일 이름이 index.html이 아닙니다. 저장소에서 파일 이름을 확인하세요.
③ 저장소가 Private입니다. Settings 맨 아래에서 Public으로 바꾸세요.

Settings에 Pages 항목이 안 보입니다

저장소 안의 Settings가 아니라 내 계정 Settings에 들어간 것입니다. 저장소 이름이 보이는 화면에서 위쪽 탭의 Settings를 누르세요.

파일을 올렸는데 화면이 그대로입니다

브라우저가 옛 화면을 기억하고 있습니다. 강력 새로고침 (Ctrl/⌘ + Shift + R)을 하세요. 그래도 안 되면 1분 더 기다렸다 다시 해 보세요.

Claude가 코드를 여러 조각으로 나눠 줍니다

“파일 하나짜리 HTML로 합쳐 줘. 외부 라이브러리는 쓰지 마”라고 다시 부탁하세요. 조각난 코드는 그대로 올리면 열리지 않습니다.

Claude 무료 사용량이 다 됐다고 나옵니다

무료 계정은 일정 시간마다 사용량이 다시 채워집니다. 몇 시간 뒤 이어서 하세요.

그래서 만든 파일은 그때그때 내 컴퓨터에 저장해 두는 것이 중요합니다. 대화를 못 열어도 파일만 있으면 언제든 다시 올릴 수 있습니다.

완성품처럼 잘 안 만들어집니다

오늘은 뼈대만 있으면 충분합니다. 완성품은 6주에 걸쳐 쌓은 결과입니다.

참고할 화면이 필요하면 완성품 페이지를 열어 두고 “이런 느낌으로 만들어 줘”라고 설명해 주세요.
